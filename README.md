# homebrew-tap

Personal Homebrew tap for georgearnall's CLI tools.

```
brew install georgearnall/tap/spacelift-notifier
```

## Releasing a new version

Casks in this tap are generated by GoReleaser; don't edit them by hand. To
release, push a semver tag in the source repo
(`git tag vX.Y.Z && git push origin vX.Y.Z`) and its release workflow updates
the cask here.
